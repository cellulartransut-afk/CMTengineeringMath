# 07. Cost codes

As of 2026-11-04. The same list is in `consultant/tools/cost-code-book.xlsx` (sheet Cost Codes).

## What a cost code is and why you use one

A cost code is a short number for a type of work, like `09-30` for tile. Every estimate line, every purchase, every sub invoice and every receipt gets a code. That lets you compare what you **estimated** against what you **spent**, item by item, on every job. Without codes, you only find out you lost money at the end, and you don't know where. With codes, you see it the week it happens, and your next estimate gets better because you know your real costs.

The divisions follow the old 16-division layout of CSI MasterFormat, the system most North American estimators and architects use, cut down for a small Bahamian contractor. If you later work with US architects or bigger GCs, the numbers will look familiar.

## How to write a code

`DD-NN-T`

- `DD` division (two digits)
- `NN` item in that division
- `T` cost type letter

Example: `09-30-S` = tile, done by a sub. `03-30-M` = concrete supply, material. `01-40-O` = skip bins, other.

## Cost types

| Letter | Type | Means |
|---|---|---|
| M | Material | Things you buy that become part of the work: block, tile, paint, fixtures. Landed and delivered cost. |
| L | Own labour | Wages of your own employees on this job, plus employer NIB. Use the Labour Cost sheet in estimator.xlsx. |
| S | Subcontract | A sub's price for a scope of work, labour only or labour and materials. |
| E | Equipment and rentals | Mixers, compactors, scaffolding, generators, trucks hired or charged to the job. |
| O | Other | Fees, freight, travel, permits, dump fees: job costs that are not M, L, S or E. |

## Rules

1. Use the same codes on the estimate, the job cost tracker, purchase orders, sub agreements and receipts.
2. Write the code on every receipt before you file it.
3. Change order costs keep the normal code; put the change order number in the notes.
4. Don't invent new codes on the fly. If you need one, add it to this list and the spreadsheet, using an unused number in the right division.
5. Overhead (costs of the company, not a job) uses the OH codes at the bottom, never job codes.
