# SOP-07 Daily Site Management
Rev 1 · 2026-11-04 · Process owner: Superintendent (the owner until hired)

**Purpose:** Run every active site every day in this order: safety, quality, schedule, cost. Write it all down.

**When:** Every working day a job is active, and every Friday for the weekly routine.

**Who:** Now: the owner. Later: the superintendent runs the day; the PM runs the weekly items.

**Forms and tools:**
- [daily-report.md](../templates/daily-report.md)
- [05-field-playbook.md](../knowledge/05-field-playbook.md): the super's daily routine, weekly routine, running subs, running the client
- [job-cost-tracker.xlsx](../tools/job-cost-tracker.xlsx): Look-Ahead, Budget & Cost Report, Change Orders

**Steps:**
Daily:
1. Visit every active site every working day. If you cannot get to every site, you have too many jobs.
2. Arrive before the crews. Walk the site for safety first: edges, scaffolds, ladders, cords, trenches, heat (SOP-12).
3. Give a 5-minute toolbox talk on one topic. Record it.
4. Check who is on site against the plan: right sub, right crew size, right work.
5. Inspect yesterday's work. Reject defects in writing the same day (SOP-08).
6. Check deliveries against the delivery notes (SOP-05).
7. Photograph progress and anything about to be covered up. Back up the phone the same day (SOP-15).
8. Write down any client or architect instruction word for word. Confirm it by WhatsApp or email the same day. If it changes scope, it goes through SOP-09 before anyone touches it.
9. Plan tomorrow: call the subs, confirm deliveries and inspections. Update the look-ahead if anything moved.
10. Before you leave: site secured, materials covered, tools locked, gate shut.
11. Write the daily report before the end of the day. Five minutes. Every working day, even when nothing happened.

Weekly, by Friday:
12. Send the client an update: progress, photos, decisions needed with dates, money status.
13. Update the three-week look-ahead and send it to the subs.
14. Run the cost check in Budget & Cost Report: budget, committed, spent, forecast to finish, per cost code. Any code over budget gets a written reason and a fix.
15. Update the change order log. Unsigned changes get chased, not built.
16. Check invoices went out on schedule (SOP-10) and accepted sub work is ready for the pay run (SOP-11).

**Done when:** A daily report and photos exist for every working day of the job, and a client update went out every week.

**Records:** 07 Daily Reports: daily reports, toolbox talk log, weekly client updates. 08 Photos: one folder per day. Look-Ahead and cost check in the job's tracker.

**Mistakes this prevents:**
- Losing an argument about what was said or done because nobody wrote it down.
- A sub falling a week behind before you notice.
- A cost overrun found at the end, when it is too late to fix.
- The client hearing bad news late. Clients forgive problems; they don't forgive surprises.

**Review triggers:** A dispute where the records were not enough; a safety hazard that the morning walk missed; a superintendent is hired and takes this over.
